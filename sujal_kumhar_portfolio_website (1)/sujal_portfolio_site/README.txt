SUJAL KUMHAR — VIDEO EDITOR PORTFOLIO

CONTENTS
- index.html: the editable portfolio website
- videos/: the five video projects you uploaded

PREVIEW
Open index.html in Chrome or another modern browser.

CUSTOMISE
Scroll to the bottom of the website and expand "Website editor — customise your portfolio".
You can change the display name, Instagram username and introduction, and add extra videos.
Those editor changes are saved in the current browser only.

PUBLISH ONLINE
1. Extract this ZIP.
2. Upload the extracted sujal_portfolio_site folder contents (index.html and videos folder) to a static hosting service such as Netlify Drop or GitHub Pages.
3. Keep the videos folder beside index.html so the project videos load.
4. If you add videos through the on-page editor, those additions are local to your browser; to publish them for everyone, add the video file into the videos folder and update index.html with a matching video path.
